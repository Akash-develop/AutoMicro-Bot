AutoMicro-Bot — Quickstart (TXT)
================================

This project has two parts:
- back-end/  (FastAPI + LangGraph agent)  -> http://localhost:8000
- front-end/ (Tauri + React UI)           -> Vite dev http://localhost:5173


Prerequisites
-------------
- Node.js 18+
- Python 3.11+
- Poetry
- Rust toolchain (for Tauri)
- Ollama installed and running (if using local models)


Backend (Python)
---------------
cd back-end
poetry install
cp .env.example .env

# (Optional) pull a local model
ollama pull llama3

# Start FastAPI
poetry run start

Backend URL: http://localhost:8000
Streaming (SSE): POST http://localhost:8000/chat/stream


Frontend (Tauri + React)
------------------------
cd front-end
npm install

# Start Tauri dev (starts Vite automatically)
# Note: Dev does NOT require bundling the backend sidecar binary.
npm run tauri:dev

# Production build (bundles backend sidecar)
# This requires the sidecar binary to exist and be prepared during build.
npm run tauri:build


Common issues
-------------
- If UI can’t connect: ensure backend is running on port 8000.
- If you changed ports: frontend has BASE_URL hardcoded in:
  front-end/src/api/chat.js and front-end/src/api/settings.js


UI automation stack (optional)
------------------------------
- Enable `run_ui_automation` and per-layer toggles in Settings (Permissions).
- DOM layer: start Chrome with remote debugging, e.g.
  /Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222
  (default port 9222; override with CHROME_DEBUG_PORT).
- AX / Input: build the Swift helper once:
  cd native/AutomationHelper && swift build -c release
  Grant Accessibility (and Screen Recording for vision) in System Settings.
- DOM service deps: cd automation-dom && npm install
- Vision OCR: install Tesseract on the Mac (brew install tesseract) for pytesseract.
- JSON schemas (single source of truth): auto-bot/schema/automation/
- E2E demo scripts: auto-bot/e2e-demos/
